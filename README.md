1. What is the difference between null and undefined?
 
ans: Null means there is no value set by a developer intentionally. On the other hand undefine means unintentionally there is no value set yet.

2.What is the use of the map() function in JavaScript? How is it different from forEach()?

ans: map() and foreach() both are loop functions. map() return as array and foreach() gives individual results.

3. What is the difference between == and ===?

ans: == check the values only. === check the values and data type.

4.What is the significance of async/await in fetching API data?

ans: async/await means Asynchronous data loading. It just works on a function to load data asynchronously so that other data fetching don't have to wait for this.

5. Explain the concept of Scope in JavaScript (Global, Function, Block).

ans: scope means variable's access barrier. Global scope means the variable can be accessed from any where. Function scope means the varial written in the function is only accessible inside the function. Block scope works inside 2nd brackets (var does not follow this rule).
